What ships today, and what is next.

Stageproof is free and open source (Apache-2.0). Rows marked Ships are in the single-binary v0.5.2 release. Rows marked Planned are not built yet.

StatusItemWhat it means
Ships File checks and values proof Render, values keys proven by template walk and rendering (--values-proof default|full, verified renames, changed defaults), removed Kubernetes APIs, immutable selectors, oversized CRDs. Uncertain values keys are proven by rendering.
Ships Pull request check stageproof check-pr reads git diff, checks every changed Helm chart, Argo CD Application (multi-source, local paths, .yaml.tmpl), and Flux HelmRelease, and writes one comment and one JSON or SARIF report.
Ships Flux HelmRelease and rendered manifests Reads Flux HelmRelease (v2, v2beta2, v2beta1, valuesFrom, spec.upgrade.crds) and compares raw rendered YAML trees with --before and --after.
Ships Local API server proof, impact, and CRD safety Runs a local Kubernetes API server (--api-server auto) to validate updates, immutable fields, and stored custom resources against upgraded CRDs; classifies deletes, restarts, exposure, privilege, capacity, and crds/ vs templates/ breaks.
Ships Image tag checks and Helm 4 readiness Checks new or changed image tags and node architectures via HTTP HEAD (--offline skips it), reports chart deprecation, warns on apiVersion: v3, and compares renders across two helm binaries with --helm-compare.
Ships Read-only cluster facts, explain, SARIF, ignores, and policy Adds stageproof facts export and --cluster-facts (get and list only, no values), stageproof explain <rule-id>, structured summary sections, --format sarif, and base-ref .stageproof.yaml ignores, policy, and live smoke commands.
Ships Live rehearsal --live installs, upgrades, runs base-ref smoke commands, and rolls back in a temporary kind cluster on the machine that runs the command. Result PROVEN when that succeeds. --require-rehearsal makes a missing rehearsal NOT CHECKED.
Ships Measured accuracy gate Phase 1 accuracy gate passed on ubuntu-latest on 2026-11-25 (docs/accuracy.md, run 45519144615): 18/18 active incidents caught, 18/18 controls passed, 0/283 (0.00%) wrong blocks across 316 CNCF upgrade pairs covering 105 CNCF projects, p95 3.47s file check and 13.71s API server proof.
Ships Pull request comment command stageproof comment posts or updates one GitHub or GitLab comment from the Markdown report.
Ships MCP server stageproof mcp serves check, check_pr, and explain on stdin and stdout. Paths stay inside --root.
Ships Public upgrade index Chart-default upgrade reports for 300 public Helm charts, more than 20,000 pairs, are published at stageproof.github.io/index. Each report uses the chart's default values, not a cluster's values. A Renovate pull request for one of those charts can show that report as a badge. The text is no blocking finding (defaults), not checked, not indexed, pair not indexed, or the blocking finding.
Planned Kustomize support Direct support for Kustomize overlays (today you can compare rendered output with --before and --after).

Terraform providers, container image contents, and language packages are outside this tool.
