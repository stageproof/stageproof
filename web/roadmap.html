PLAN In order, and labeled

What exists, and what does not.

Stageproof is a Helm and Kubernetes upgrade check. The rows marked Ships are in the CLI. The rows marked Planned are not in this release.

StatusItemWhat it means
Ships File checks Render, values keys read by templates, removed Kubernetes APIs, immutable selectors, oversized CRDs. Result PASSED or BLOCKED.
Ships Pull request check stageproof check-pr reads git diff, checks every changed chart, Argo CD Application, and Flux HelmRelease, and writes one comment and one JSON report. The v0.1.8 binary does not read a HelmRelease.
Ships Live rehearsal --live installs, upgrades, and rolls back in a temporary kind cluster on the machine that runs the command. Result PROVEN when that succeeds. --require-rehearsal makes a missing rehearsal NOT CHECKED.
Ships Flux HelmRelease Source on main reads spec.chart, spec.chartRef, spec.values, spec.valuesFrom, and spec.upgrade.crds. A chart in another Git repository is NOT CHECKED. The v0.1.8 binary does not.
Planned An engine people can measure The accuracy corpus, including a replay of public Flux upgrades that prints only counts and timings, the local API server proof, the impact report, values proof by rendering, image tag checks, and a Helm 4 render comparison ship in source on main. The released binary is v0.1.8. Still planned: Kustomize.
Planned A public upgrade index An upgrade report for version pairs of public charts, with a page, an API, and a badge a pull request can show.

Terraform providers, container image contents, and language packages are outside this tool.
