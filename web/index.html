01 Why a green chart check is not enough

Helm does not compare the upgrade.

Three failures come from that gap. Stageproof looks for them while the change is still a pull request.

Valueshelm.values.silently_dropped

A setting you rely on stops working

The new chart renames or removes a values key. Helm ignores the old key without an error, so your override is no longer applied.

APIk8s.api.removed

The chart uses an API your cluster no longer serves

Kubernetes removes old API versions over time. A chart that still emits one fails when it is applied.

Upgradek8s.upgrade.immutable_selector_changed

The upgrade cannot be applied in place

Some fields cannot change on a running workload, such as the label selector of a Deployment. A fresh install works. The upgrade fails.

02 What ships

One command. Four input types. A result you can gate on.

stageproof check compares two chart directories, an Argo CD Application, a Flux HelmRelease, or two rendered manifest trees. stageproof check-pr finds the charts, Applications, and HelmReleases a git diff touched and checks each one. A deleted file inside a chart still counts. Flux HelmReleases and rendered manifest trees are included.

03 Results

Four names. Three exit codes.

A file check that passes is a success. It is not a warning. The report says checked: files so you can see that no cluster was used.

PROVENexit 0

File checks passed, and the upgrade and the rollback both worked in a temporary cluster. checked: files, live cluster.

PASSEDexit 0

File checks passed. The upgrade was not rehearsed, or the rehearsal stopped for a reason outside the chart.

BLOCKEDexit 1

The upgrade has a problem the report names. A CI job should fail.

NOT CHECKEDexit 2

The check did not finish, or --require-rehearsal was set and no rehearsal ran. A CI job should fail. It does not say the upgrade is unsafe.

04 Scope

Kubernetes upgrades.

Supported

A Helm chart in a directory. An Argo CD Application, including several sources and a chart path in this repository, and a Terraform .yaml.tmpl with placeholders. A Flux HelmRelease. Two rendered manifest trees. A pull request, by reading git diff. It does not call Renovate or GitLab to find out what changed.

Not supported

Terraform providers and modules. Container image contents. Kustomize and Helmfile. A loose manifest in a pull request stays ignored. Compare rendered trees with stageproof check --before and --after. Language packages.

What --live does

It starts a temporary kind cluster on the machine running the command, installs the current chart, upgrades to the new chart, rolls back, and deletes the cluster. It does not commit, and it does not change a cluster you already have. The node is itself a container, so an unprivileged CI job cannot start it. That job stays on the file check.
